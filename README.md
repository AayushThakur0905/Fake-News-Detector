# 🔎 FactCheck AI — Fake News Detector

FactCheck AI is an AI-powered web application that analyzes news claims using relevant news sources and Natural Language Inference (NLI). It classifies evidence as supporting, contradicting, or neutral and generates an overall verdict with an evidence confidence score.

## 🌐 Live Demo

**[Try FactCheck AI](https://fake-news-detector-pz24uhq2cvcki8aolmavix.streamlit.app/)**

## 🛠️ Tech Stack

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch
- FastAPI
